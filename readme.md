# @drabc/koishi-plugin-duel

[![npm](https://img.shields.io/npm/v/@drabc/koishi-plugin-duel?style=flat-square)](https://www.npmjs.com/package/@drabc/koishi-plugin-duel)

Koishi 决斗插件 (duel)

一个简单有趣的 Koishi 插件，允许用户在群聊中发起“西部决斗”：两人匹配后进入倒计时，倒计时结束后谁先发送 `拔枪` 谁获胜，提前拔枪者将被禁言！

## 📦 安装

在你的 Koishi 项目根目录下运行：

```bash
npm install koishi-plugin-duel
# 或
yarn add koishi-plugin-duel
